# dazebot
A utility Discord bot managing functionality for the Wynncraft "Returners" veterans community.

The Python package is named `nazbot` (in `pyproject.toml` / `uv.lock`) for historical reasons, but the bot itself is **dazebot**. The bot named *nazbot* lives in [`../temporary-server`](https://github.com/Wynncraft-Veterans/temporary-server) and handles the in-game ↔ Discord chat bridge — don't conflate the two.

Project-level docs and reference material live in [`../.claude/`](../.claude/).
